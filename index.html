核心邏輯

純多方策略。收盤價連續 2 根站上 1280 根K棒 High 均線、且均線本身連續 2 根上揚才進場；出場完全不主動停損停利，只靠每月第三個週三結算日強制平倉。近似「趨勢一旦確立就抱到底」的買進持有邏輯。

主要優勢

全系列淨利與獲利因子最高，且大幅領先第二名；交易僅 103 筆，每筆平均獲利約 6.9 萬元居冠，是十五個版本中對滑價／手續費最不敏感的版本。

風險與適用情境

最大策略虧損 -113.2% 只是中段班，因為完全沒有主動風控，遇到單次大幅拉回會直接承受。適合能接受較大帳面波動、以長期總報酬效率為優先的使用者。

查看完整程式碼 · PowerLanguage（TXF_15M_1280HighMA_2Bar_BH_Settlement_v1.txt） 
Inputs:
    TrendLen(1280),
    ExitDay(3),
    MinDay(15),
    MaxDay(21);

Variables:
    HighMA(0),
    Condition1(false),
    IsSettlementDay(false);

// Calculate the average of the highest prices
// over the previous 1280 bars
HighMA = Average(High, TrendLen);

// Identify the third Wednesday of each month
// DayOfWeek = 3 represents Wednesday
IsSettlementDay =
    DayOfWeek(Date) = ExitDay
    and DayOfMonth(Date) >= MinDay
    and DayOfMonth(Date) <= MaxDay;

// Entry condition:
// 1. The closing price has been above the 1280-bar
//    high-price moving average for two consecutive bars.
// 2. The moving average itself has been rising
//    for two consecutive bars.
Condition1 =
    Close > HighMA
    and Close[1] > HighMA[1]
    and HighMA > HighMA[1]
    and HighMA[1] > HighMA[2];

// Enter a long position on the next bar at market
// when the strategy is not currently long.
If MarketPosition <> 1
and Condition1 then
    Buy ("LongEntry") Next Bar at Market;

// Exit the position at the end of the settlement day.
If IsSettlementDay then
    SetExitOnClose;

核心邏輯

在 v1 的 1280 HighMA 趨勢濾網上，疊加 MACD 柱狀圖 > 0（動能確認）與 RSI > 50（多方力道確認）雙重過濾；出場改用 BB(20,2) 中軌動態跌破（僅獲利時觸發）＋結算日強制出場。相較 v4/v5 用 BB 下軌，v3 用中軌出場明顯更敏感、更早停利了結。

主要優勢

勝率 90.35% 是全系列（含所有微調版本）最高，帳戶所需金額 684,800 元也是六版中最低，代表資金效率最佳、心理上最容易「常常是對的」。

風險與適用情境

交易總次數 902 筆偏高，對實盤滑價／手續費敏感度較高；曾以 v3.1 加入 10 根K棒冷卻期測試，交易次數完全沒變（902 筆不變），證實瓶頸不是缺乏冷卻期，而是 BB 中軌出場本身過於敏感、獲利常常提早了結。適合重視「常勝」心理感受、能接受較高交易頻率成本的使用者。

Inputs:
    TrendLen(1280),
    ExitDay(3),
    MinDay(15),
    MaxDay(21),
    // Momentum and volatility filter parameters
    MacdFastLen(12),
    MacdSlowLen(26),
    MacdMacdLen(9),
    RsiLen(14),
    BBLength(20);

Variables:
    HighMA(0),
    MacdValue(0),
    MacdAvg(0),
    MacdDiff(0),
    RsiValue(0),

    Condition1(false),

// ======================================================
// 1. Core trend and multi-dimensional technical indicator calculation
// ======================================================
HighMA = Average(High, TrendLen);

// Calculate MACD (assess breakout momentum)
MacdValue = MACD(Close, MacdFastLen, MacdSlowLen);
MacdAvg = XAverage(MacdValue, MacdMacdLen);
MacdDiff = MacdValue - MacdAvg; // MACD Histogram

// Calculate RSI (assess bullish strength)
RsiValue = RSI(Close, RsiLen);

// Calculate Bollinger Bands midline (dynamic trailing stop)
BBMid = Average(Close, BBLength);


// ======================================================
// 2. Settlement day condition check
// ======================================================
IsSettlementDay =
    DayOfWeek(Date) = ExitDay
    and DayOfMonth(Date) >= MinDay
    and DayOfMonth(Date) <= MaxDay;


// ======================================================
// 3. Entry logic (Trend + Momentum + Strength confirmation)
// ======================================================
Condition1 =
    // Original logic: Price above 1280 HighMA and MA rising for 2 consecutive bars
    Close > HighMA
    and Close[1] > HighMA[1]
    and HighMA > HighMA[1]
    and HighMA[1] > HighMA[2]
    // New filter: MACD histogram > 0, ensuring upward momentum
    and MacdDiff > 0
    // New filter: RSI > 50, ensuring bullish control zone
    and RsiValue > 50;

// Execute long entry
If MarketPosition <> 1 and Condition1 then
    Buy ("LongEntry_Opt") Next Bar at Market;


// ======================================================
// 4. Exit logic (Dynamic trailing stop + Mandatory settlement exit)
// ======================================================
If MarketPosition = 1 then 
begin
    // Dynamic stop: Exit if close falls below 20-bar BB midline and position is profitable
    If Close < BBMid and OpenPositionProfit > 0 then
        Sell ("BB_TrailExit") Next Bar at Market;

    // Settlement day final defense: Hold until the close of the 3rd Wednesday
    If IsSettlementDay then
        SetExitOnClose;
end;

核心邏輯

進場濾網最嚴格（要求同根爆量），訊號會比 v5 更少更保守。適合想要「看得懂、抱得住」且對實盤成本、資金規模敏感的穩健型使用者。

查看完整程式碼 · PowerLanguage（TXF_15M_VolKD_CoolDown_Settlement_v4.txt） 
// Strategy Name: TXF_15M_VolKD_CoolDown_Settlement_v4

Inputs:
    TrendLen(1280),
    ExitDay(3),
    MinDay(15),
    MaxDay(21),
    // Live Volume filter parameters
    VolLen(20),
    VolMult(1.5),
    // KD Oscillator parameters
    KLen(9),
    DLen(3),
    // Bollinger Bands exit parameters
    BBLength(20),
    BBDev(2),
    // Cooldown parameter to prevent over-trading
    CooldownBars(10);

Variables:
    HighMA(0),
    AvgVol(0),
    LowestLow(0),
    HighestHigh(0),
    KValue(0),
    DValue(0),
    BBLower(0),
    ExitBar(-999),
    CanEnter(true),
    IsSettlementDay(false),
    Condition_Trend(false),
    Condition_Vol(false),
    Condition_KD(false);

// ======================================================
// 1. Core trend, live volume, and KD calculations
// ======================================================
HighMA = Average(High, TrendLen);
AvgVol = Average(Volume, VolLen); 

// Calculate KD (Stochastic Oscillator)
LowestLow = Lowest(Low, KLen);
HighestHigh = Highest(High, KLen);

If HighestHigh <> LowestLow Then
    KValue = (Close - LowestLow) / (HighestHigh - LowestLow) * 100
Else
    KValue = 0;

DValue = Average(KValue, DLen);

// Calculate Bollinger Bands Lower Band (Relaxed dynamic stop)
BBLower = Average(Close, BBLength) - BBDev * StandardDev(Close, BBLength, 1);


// ======================================================
// 2. Cooldown period logic (Prevent consecutive whipsaws)
// ======================================================
// Record the bar number when a long position is closed
If MarketPosition = 0 and MarketPosition[1] = 1 Then
    ExitBar = CurrentBar;

// Check if enough bars have passed since the last exit
CanEnter = (CurrentBar - ExitBar) > CooldownBars;


// ======================================================
// 3. Settlement day condition check
// ======================================================
IsSettlementDay =
    DayOfWeek(Date) = ExitDay
    and DayOfMonth(Date) >= MinDay
    and DayOfMonth(Date) <= MaxDay;


// ======================================================
// 4. Entry logic (Trend + Volume Burst + KD Confirmation)
// ======================================================
Condition_Trend =
    Close > HighMA
    and Close[1] > HighMA[1]
    and HighMA > HighMA[1]
    and HighMA[1] > HighMA[2];

// Volume burst requirement
Condition_Vol = Volume > (AvgVol * VolMult);

// KD golden cross and not in overbought territory
Condition_KD = KValue crosses over DValue and KValue < 80;

// Execute long entry if all dimensions align and cooldown is cleared
If MarketPosition = 0 and CanEnter and Condition_Trend and Condition_Vol and Condition_KD then
    Buy ("Long_v4") Next Bar at Market;


// ======================================================
// 5. Exit logic (Relaxed Trailing Stop + Settlement)
// ======================================================
If MarketPosition = 1 then
begin
    // Relaxed dynamic stop: Exit if close falls below the BB lower band
    If Close < BBLower and OpenPositionProfit > 0 then
        Sell ("BB_TrailExit") Next Bar at Market;

    // Settlement day final defense
    If IsSettlementDay then
        SetExitOnClose;
end;

核心邏輯

// Strategy Name: TXF_15M_AsyncVolKD_AtrBE_BBTrail_v10
// Tab Name: 15M_AtrBE_v10

Inputs:
    TrendLen(1280),         // Core trend determination
    ExitDay(3), MinDay(15), MaxDay(21), 
    // Async Volume & KD filters 
    VolLen(20), VolMult(1.5), VolLookback(10),
    KLen(9), DLen(3),
    CooldownBars(10),
    // v10 Core: ATR Adaptive Defense Parameters
    AtrLen(14),             // ATR calculation period
    IslAtrMult(4),          // Initial Stop Loss multiplier (e.g., 4x ATR)
    BeTriggerAtrMult(3),    // Smart Breakeven trigger threshold (3x ATR profit)
    BeLockAtrMult(0.5),     // Breakeven lock level (Entry + 0.5x ATR to cover costs)
    // Bollinger Bands Defense
    BBLength(20), BBDev(2);

Variables:
    HighMA(0), AvgVol(0), HighestVol(0),
    LowestLow(0), HighestHigh(0), KValue(0), DValue(0),
    BBLower(0), MyATR(0), EntryATR(0), 
    ExitBar(-999), CanEnter(true), IsSettlementDay(false),
    BE_Triggered(false),    // Tracks if Breakeven has been activated
    Condition_Trend(false), Condition_Vol(false), Condition_KD(false);

// ======================================================
// 1. Indicator Calculations and State Updates
// ======================================================
HighMA = Average(High, TrendLen);
AvgVol = Average(Volume, VolLen); 
HighestVol = Highest(Volume, VolLookback);

LowestLow = Lowest(Low, KLen);
HighestHigh = Highest(High, KLen);
If HighestHigh <> LowestLow Then KValue = (Close - LowestLow) / (HighestHigh - LowestLow) * 100 Else KValue = 0;
DValue = Average(KValue, DLen);

BBLower = Average(Close, BBLength) - BBDev * StandardDev(Close, BBLength, 1);
MyATR = AvgTrueRange(AtrLen);

// ======================================================
// 2. Cooldown, Settlement, and State Reset
// ======================================================
If MarketPosition = 0 Then 
begin
    BE_Triggered = false; // Reset breakeven state when flat
    If MarketPosition[1] = 1 Then ExitBar = CurrentBar;
end;

CanEnter = (CurrentBar - ExitBar) > CooldownBars;
IsSettlementDay = DayOfWeek(Date) = ExitDay and DayOfMonth(Date) >= MinDay and DayOfMonth(Date) <= MaxDay;

// ======================================================
// 3. Entry Logic (Multi-dimensional Alignment)
// ======================================================
Condition_Trend = Close > HighMA and Close[1] > HighMA[1] and HighMA > HighMA[1] and HighMA[1] > HighMA[2];
Condition_Vol = HighestVol > (AvgVol * VolMult);
Condition_KD = KValue > DValue;

If MarketPosition = 0 and CanEnter and Condition_Trend and Condition_Vol and Condition_KD then
begin
    Buy ("Long_v10") Next Bar at Market;
    EntryATR = MyATR; // Capture the True Range at the moment of entry
end;

// ======================================================
// 4. Exit Logic (Adaptive ISL -> Smart BE -> BB Trail -> Settlement)
// ======================================================
If MarketPosition = 1 then
begin
    // Check if the Smart Breakeven threshold has been reached
    If High >= EntryPrice + (EntryATR * BeTriggerAtrMult) Then
        BE_Triggered = true;

    // Defense A: ATR Dynamic Initial Stop Loss
    If Close < EntryPrice - (EntryATR * IslAtrMult) Then
        Sell ("ATR_ISL") Next Bar at Market;

    // Defense B: Smart Breakeven Mechanism (Lock in minor profit to cover slippage)
    If BE_Triggered and Close < EntryPrice + (EntryATR * BeLockAtrMult) Then
        Sell ("SmartBE_Exit") Next Bar at Market;

    // Defense C: BB Lower Band Trailing (Exit if below BB and profitable)
    If Close < BBLower and OpenPositionProfit > 0 Then
        Sell ("BB_TrailExit") Next Bar at Market;

    // Defense D: Mandatory Settlement Exit
    If IsSettlementDay then
        SetExitOnClose;
end;
